## 项目简介

这是一个**开源的、社区驱动的**付鹏宏观分析思维框架提炼项目。

付鹏，东北证券前首席经济学家，现任 Bitfire Group、Avenir Capital 首席经济学家，兼任新火集团（港股 1611.HK）首席经济学家。曾旅居伦敦，任职雷曼兄弟、所罗门国际投资集团等对冲基金，亲历 2008 年金融危机。

核心研究领域：全球宏观框架（FICC）、Crypto 资产配置、AI 周期与生产力变革、逆全球化传导机制。

⚠️ **免责声明**：本框架基于付鹏公开资料（书籍、专栏、演讲、视频）系统性提炼生成，仅供学习研究使用，不构成任何投资建议。

本仓库同时是一条**可持续蒸馏管线**：自动采集三平台（YouTube / B站 / 抖音）付鹏最新视频与书籍 → 本地 ASR 转录 → LLM 蒸馏成可执行技能，按上述框架结构持续更新。

## 核心框架

```
全球金融货币秩序重构 → 资产分化 → 跨资产联动 → 证伪验证
```

这是一条从**制度层**到**资产层**的自上而下传导链。付鹏认为，绝大多数人盯着 GDP、利率、财报这些"结果"，而真正的"原因"藏在金字塔顶端——意识形态 → 制度 → 生产关系 → 宏观经济 → 产业 → 企业。

## 心智模型（7个）

| # | 模型 | 来源 | 核心洞察 |
|---|------|------|------|
| 1 | **AI 基建周期证伪模型** | Alpha 峰会演讲 | "路修好了，等待车跑"——上游算力基建完备，下游应用等待证伪。2026 年是"证实/证伪之年" |
| 2 | **Crypto+FICC 融合框架** | 2026 年香港 Web3 演讲 | 比特币 = "具有价值维护功能的可交易金融资产"。Crypto 不是资产类别，是金融操作系统升级 |
| 3 | **逆潮传导链** | 《见证逆潮》 | 贸易逆全球化 → 供应链重构 → 通胀黏性 → 政策两难 → 金融逆全球化 |
| 4 | **齿轮联动模型** | 《见证逆潮》+ 阿西莫格鲁 | 生产力变革 → 生产关系调整 → 制度秩序重构，三者如齿轮咬合联动 |
| 5 | **TFP 锚定模型** | 《见证逆潮》+ 阿西莫格鲁 | 长期资产价值由全要素生产率（TFP）决定，而非货币政策 |
| 6 | **波动率资产化** | 投资实践 | 结构变化期，波动率本身成为可交易的资产类别 |
| 7 | **情景证伪思维** | 分析方法论 | 对核心判断设定情景锚定，明确证伪标准——无法被证伪的观点不是完整分析 |

## 决策启发式（9条）

### 来自《见证逆潮》

- **逆潮传导**：逆全球化信号出现 → 预设 2-3 年传导时滞
- **齿轮联动**：生产力变革发生 → 问"制度和生产关系跟上哪一步了？"
- **TFP 判断**：TFP 增速放缓 → 12-24 个月等待权益市场重新定价
- **政策两难**：央行面临两难 → 政策锚失效，波动率溢价上升

### 来自公开分析（含视频内容）

- **AI 周期**：AI 基建完成但应用未兑现 → 12-18 个月等待证伪
- **Crypto 配置**：监管明确且机构开始配置 → 6-12 个月内跟随
- **家庭理财**：经济不确定性高 → 降负债、配保险是首选
- **波动率**：市场波动加剧 → 用期权或波动率产品对冲
- **情景验证**：观点无法被证伪 → 这不是一个完整的分析

| 特征 | 表现 |
|------|------|

## 作为分析工具使用

面对任何宏观问题，按以下顺序自问：

1. 它在**逆潮传导链**的哪一环？
2. **齿轮联动**中，制度和生产关系跟上哪一步了？
3. **TFP** 能支撑这个估值吗？
4. **证伪标准**是什么？

## 价值观

- **数据验证 > 叙事逻辑**——实事求是
- **框架清晰 > 预测准确**——好的框架比准确的预测更有价值
- **承认不确定性 > 假装确定性**——不确定的地方直接说
- **跨资产联动 > 单一资产分析**——全局视角才能看清方向
