# 付鹏"澳新房地产出清高潮 · 影子监管真空 · 汇率化解债务"框架（做空澳新 10 年复盘：双杀备忘录，出清在高潮上悄悄上演）

来源：付鹏 2026《[鹏说] 双杀备忘录-新西兰：阴阳面中的大观》（YouTube `v86YxyUYeYs`，40:37）。
参考文件：`references/source-v86YxyUYeYs.txt`（论点带 [MM:SS]）。

## 总纲
2014 年起付鹏一直在**做空澳大利亚 + 新西兰（澳新）**的大宏观周期，2016 年 8 月（整整十年前）他密集调研澳大利亚金融监管三巨头——**RBA（联储）+ APRA（审慎监管局）+ ASIC（证券和投资委员会）**——发现 APRA 已就"房地产/银行信贷潜在风险"出报告并准备"轮下第一版"收紧。这场十余年的游戏，现在（2026）正走到**出清的高潮**，而非结束。核心链条：前端开发/拿地/商业地产被银行"剃出去"（玻璃隔离），只剩居民按揭 → 高房贷侵蚀居民部门（购买力、日常消费、新房购房、二手房周期全差）→ 成本挤压+无法交付+高利率信用紧缩形成**反向正反馈螺旋** → 影子银行/私募信贷"监管真空"无人管 → 最终国家能否扛过周期，**看居民部门真实生产力与自然负债表**，而非房地产。利率两难：RBA 夹紧了居民（月供多上千澳元）、不夹就落后美联储、澳元贬值 → 大概率走**新西兰式的"汇率式编织"**（实际有效汇率大幅下调来化解本国债务，3-5 年游戏）。

## 何时用
- 分析澳大利亚/新西兰**房地产 + 居民杠杆 + 汇率**的多头/空头逻辑
- 判断**影子银行 / 私募信贷 / 监管真空**（影子资金池归谁管、靠市场出清）
- 用"一个国家扛周期最终看**居民真实生产力 + 自然负债表**"做跨市场对照（对拍中国 2018-2023 影子银行→居民端传导→23 年金融监管总局成立）
- 讨论**"汇率式债务化解"（汇率式编织）**路径（新西兰 vs 澳大利亚）
- 复盘"监管部门**前置信号**"（看报告、看接下来怎么做，而非等 A 直接倒闭）

## 心智模型

### M1. 监管的前置信号 + 三层反馈路径（非一蹴而就）[02:43-03:45, 07:00]
- 监管（APRA 报告）本质是**前置**的：它对系统性风险做"前瞻性提示"。
- 看到监管动作 ≠ 明天就出事（韩国把 2 倍做空/做多 ETF 搞回去也不代表立刻崩），而是**风暴酝酿的序曲**、"即将开始"。
- 大宏观周期（澳新 2013 起 10-15 年）的每个环节**不是 A 直接倒闭**，而是一条**反馈路径**；需"系统性长周期视角" + "必须知道某些事情代表什么"（日历/信号意识）。

### M2. 监管"修隔离带"而非"灭火"（玻璃隔离前端开发）[05:00-05:40, 11:10]
- 监管一旦发现水下风险，第一动作是**修住防火带/隔离带**（前置收紧），不是扑火。
- APRA 把银行前端开发（拿地/商业地产）**"剃出去"**，对开发类做"玻璃隔离"，但**依旧做居民按揭**（"银行的标准左右名——只做惊（警）商天花"）。
- 后果：风险**转移**到监管看不清的**影子/私募信贷池**（"影子综界、监管真空"，费营资金池归谁管无定论）。

### M3. 高房贷侵蚀居民部门 = 出清的高潮 [36:21, 38:46]
- "高房贷已经侵蚀居民部门了"：购买力、日常消费、新房购房、二手房周期**全差**（悉尼/墨尔本中餐馆/华人餐厅/夜总会经营都不好了）。
- 成本挤压 + 无法交付 + 高利率信用紧缩 → **反向正反馈螺旋**。
- 唯一支撑=**住房供求相对紧**（澳新城市不像国内部分城市极端过市），但"力量更倾向于对居民部门打幅度侵蚀，而不是侵蚀的支撑"。

### M4. 利率两难 → 新西兰式"汇率式债务化解" [35:02-36:21]
- RBA **夹（加息）不行**：居民端多为浮动/短固利率，月供再多上千澳元、收入给不起 → 连锁反应。
- **不夹也**不行：落后美联储 → 澳元贬。
- 大概率结局=**跟新西兰一样**："澳元一（贬）、新币一（贬）" → **汇率式编织**，让实际有效汇率大幅下调来化解本国债务（"后面 3-5 年的整个游戏"）。

### M5. 扛周期底线 = 居民真实生产力 + 自然负债表 [40:01-40:19]
- 经济结构单一、最终都押注房地产，经历影子银行风险隔离后，"虚假繁荣退去"。
- "一个国家能否扛过一个周期，最终还是要看**居民部门真实的生产力和自然负债表**的情况。"
- "这场经历了十多年的新（的）游戏，正在出清的高潮上，在悄悄地上演，而不是结束。"

## 决策启发式（跨市场对照）
- **看监管**：出报告→看它接下来做什么→修隔离带=风险**转移**到影子/私募池，别只看央行。
- **对照中国**：中国 2018 资管新规+影子银行清理→地产去杠杆→2022 传导到居民端→2023 成立金融监管总局（整体穿透式监管，"只要你吸收资金发贷款就一套神（穿）监管"）。澳大利亚**仍比中国改革前宽松**：APRA 2016-17 收紧四大行"保住了账面"，ASIC 还在"打补钉"，影子池靠**市场残酷自发出清**。
- **做空信号**：前端开发被剃 + 居民按揭独撑 + 高房贷侵蚀 + 影子池无人管 = 出清高潮，**做空逻辑仍在路上、不可逆**。
